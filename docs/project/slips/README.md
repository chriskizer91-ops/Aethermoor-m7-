# Slips

Each job keeps one slip here, `slips/<job>.md`, on its own branch, and nobody else writes it. The hub reads it to know
where the job stands. Keep it short and current:

- **Done**: what works now, with the page's link and the commit.
- **Next**: what you're doing next.
- **Changed outside my files**: anything, with why (there should be little or nothing).
- **Needs**: what you need from another job or the hub.
- **For Chris**: questions only he can answer, each with your suggestion.
- **Checks**: what you ran (tests, headless loads, screenshots) and what you couldn't check (a phone's frame rate).
